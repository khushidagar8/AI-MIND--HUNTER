# 🧠 AI Mind Hunter

**AI-Inspired Brain Challenge Game using Python**

## 📌 About the Project
AI Mind Hunter is an interactive brain-challenge game designed to test logical thinking, observation, memory, and problem-solving skills through engaging challenges.

## ✨ Features
- Interactive graphical user interface
- Brain and logic challenges
- User-friendly game interface
- Python-based desktop application

## 🛠️ Technologies Used
- Python
- Tkinter
- Random module (if used in the code)

## ▶️ How to Run
1. Download or clone this repository.
2. Open the Python file in Python IDLE.
3. Select **Run → Run Module (F5)**.
4. Enjoy the game!

## 🎯 Objective
To make logical thinking and problem-solving more interactive through a fun, game-based experience.
